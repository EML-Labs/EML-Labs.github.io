The Patient-Specific SR→AF Axis
// a personalised risk compass for each patient

We map each patient's "normal" and "AFib" rhythm — then watch which way new beats drift towards.

Training
Encoder learns to separate SR and AF embeddings using patient-aware contrastive loss — keeping each patient's SR distinct.
Axis Definition
Per-patient axis u = (μ_AF − μ_SR) / ‖μ_AF − μ_SR‖ defines a personalised SR→AF direction in frozen latent space.
Inference Score
p_t = (z_t − μ_SR) · u projects any new segment onto [0,1] — a continuous, interpretable measure of AF progression.
